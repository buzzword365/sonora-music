# Sonora Music v0.3.0 — Playlists, drag selection and smarter search

Build date: 29 October 2026 · macOS Apple Silicon (arm64)

## Highlights

- **Build playlists from existing music.** Pick saved songs from the library when creating or editing playlists — no repeat import or file selection required. Selections persist while searching; bulk-select, remove and reorder tracks.
- **Drag to select or deselect.** In the playlist library picker, drag across adjacent song rows to add or remove a range. Individual clicks, checkbox keyboard controls, and existing playlist drag reordering continue to work.
- **Artwork in the picker.** Each result displays its embedded album art or a placeholder when unavailable.
- **Better artist search.** Search ignores case, spacing, punctuation and diacritic differences; `alexg`, `Alex G` and `ALEX-G` can locate tracks tagged `Alex G` or `alexgoffline`.
- **Fixed Enter handling.** Enter in playlist search no longer accidentally submits and closes the dialog.

## Quality and privacy

- Production TypeScript/Vite build and native Electron syntax checks.
- Electron playlist regression: creation, editing, error handling, keyboard focus, appearance, audio import, playback and full-restart persistence.
- Synthetic artist fixture: 22 matching tracks; verified normalised search, 22 embedded covers, drag-to-select and drag-to-deselect, checkbox interaction, save/reload, and no renderer errors.
- The public tests and distributable use synthetic data; **no personal songs, playlists, artwork collections, music-folder indexes, or account credentials are bundled.**

## Installing

Download `Sonora-Music-v0.3.0-Apple-Silicon.zip`, extract it, and open **Sonora Music.app**. Back up the old `.app` before replacing it; existing user library data is stored separately from the application bundle. Keep the music files in their original folders.

**macOS security notice:** This app is unsigned and not notarised. You may need to allow it in **System Settings → Privacy & Security** after the first launch. Built for Apple Silicon Macs.

The complete React + TypeScript source is available in this repository. `npm ci && npm run check && npm run build && npm run test:playlists` runs the main checks on macOS with Node.js 24+.
