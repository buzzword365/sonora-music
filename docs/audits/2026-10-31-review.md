## Existing protections verified in source
- Electron renderer has context isolation, sandboxing, disabled Node integration,
  and restricted navigation/window creation.
- Native local song streaming checks approved music-root paths and their resolved
  real paths before opening a file.
- LAN phone companion has pairing, authenticated cookies, method/content-type
  checks and validation of playback commands.
- No obvious credentials or key files were found in the inspected project paths.
- `npm audit`, including production dependencies, reported **0 known advisories**
  during this review. This is not a penetration test or proof of zero vulnerabilities.

## Architecture recommendation
Keep Electron as the established macOS desktop host. Maintain the shared React/Vite UI
and a separate Capacitor/WKWebView iOS host. Before recommending the iOS app for normal
listening, replace provisional WebKit-only large-audio storage with app-private native
file storage and verify AVAudioSession/background playback behaviour. Reuse components
and metadata rules rather than rewriting the desktop application.
